# Hessel de Vries — website

Statische homepage voor hesseldevries.com. Publiceer `index.html` en de volledige map `assets/` in de rootmap van het domein bij Hostnet.

GitHub is hier de broncode. Een commit in deze repository wijzigt de live site pas wanneer de bestanden ook bij Hostnet zijn geplaatst.

De huidige site draait op WordPress. Maak eerst een backup van WordPress-bestanden en database. Test de statische site op Hostnet voordat je de WordPress-applicatie en database verwijdert. Verwijder geen andere domeinmappen of e-mailinstellingen.
